Адрес: https://utkinin.github.io/Afara/

GitHub Pages успешно опубликовал ветку `gh-pages`: [проверенный запуск размещения](https://github.com/utkinin/Afara/actions/runs/38746683418). Этот адрес не зависит от процессов облачной машины.

Это отдельная публичная версия для проверки дизайна: 18 страниц, адаптивная вёрстка, меню, ссылки, оба шага формы и сохранение ввода при возврате. Кнопка серверного консультанта исключена из снимка. Отправка заявки отключена. Короткие ссылки 302 и API консультанта требуют отдельного Node-сервера и здесь отсутствуют. CMS, preview черновиков, заявки, секреты и административные API физически отсутствуют. Изображения остаются подписанными ИИ-концепциями. Страницы закрыты от индексации meta robots и robots.txt. Шрифты локальные, лицензии скопированы в `licenses/`.

## Обновление

1. Запустить основное приложение и убедиться, что опубликованное содержимое одобрено для публичного превью.
2. Выбрать **новую пустую** папку вне checkout и выполнить `PREVIEW_OUTPUT=/путь/к/новой/папке/Afara npm run preview:build`. По умолчанию источник — локальный порт 3000, префикс GitHub Pages — `/Afara`; можно переопределить PREVIEW_ORIGIN/PREVIEW_BASE.
3. Проверить экспорт статическим сервером с корнем на уровень выше папки Afara; `npm run test:preview` ожидает сервер на порту 3100, либо задайте PREVIEW_TEST_ORIGIN. Тест не использует приложение/БД: проверяет страницы, загрузку изображений, меню, шаги формы, отсутствие внешних запросов и 404 служебных маршрутов.
4. Публиковать **содержимое** папки Afara в ветку gh-pages обычным push без force, сохраняя историю. Основная ветка main содержит приложение, gh-pages — только сгенерированный публичный снимок. Не менять рабочий checkout на gh-pages и не создавать worktree для обычной облачной задачи.

Генератор отказывается перезаписывать непустую папку: это защищает пользовательские файлы и исключает сохранение старых страниц после снятия с публикации. Он читает только анонимный HTML/публичные обработанные медиа и статические ресурсы. Скрипты приложения/данные гидратации исключены; отдельный небольшой скрипт обеспечивает меню и форму без сетевых отправок. CSP запрещает connect-src и form-action.

## Проверка

Локальная копия: браузерный тест прошёл на префиксе /Afara с мобильной шириной 390 px. GitHub подтвердил успешное размещение. Прямой HTTP-запрос к github.io из onboarding-машины запрещён её сетевой политикой (CONNECT 403), поэтому проверка внешнего HTTP-ответа здесь не заявляется. Для этого в черновик настроек добавлены только api.github.com и utkinin.github.io с сохранением прежних preset-правил. Изменение черновика не активирует сетевую политику; его нужно сохранить и опубликовать в настройках среды. Открытие адреса в браузере пользователя от этой настройки не зависит.

Это проверка публичного интерфейса; полная серверная версия, сохранение заявок и защищённая CMS описаны в README.md и QA_REPORT.md.
