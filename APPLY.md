**Код обновления уже находится непосредственно в файлах этой ветки. Повторно применять патч к этой ветке не нужно.**

## Где находятся материалы

- `fixtures/editorial/manifest.json` — реестр 16 концепций и мобильных вариантов.
- `fixtures/editorial/*.webp` — все 32 изображения.
- `content/visual-collection.ts` — распределение изображений и содержание 14 направлений.
- `content/editorial-knowledge.json` — восемь подготовленных ответов с источниками.
- `scripts/import-editorial.ts` — явная подготовка CMS-черновиков.
- `docs/EDITORIAL_RESEARCH.md` — исследование, концепция и источники.
- `handoff/AFARA_Update.patch` — исходный патч относительно базового коммита `9243217641cf55d1ab2d50df5051458aca14f773`, для справки и переноса на совместимую базу. Не применять поверх уже внесённых изменений.
- `ADMIN_GUIDE.md`, `QA_REPORT.md` — инструкция владельца и границы проверок.

## Следующие действия Codex

1. Получить эту ветку и прочитать `AGENTS.md`. Не подменять её веткой `main`, в которой обновления пока нет. Сохранить текущие изменения пользователя.
2. Выполнить `npm ci`, `npm run lint`, `npm run typecheck`, `npm run build`. Для изолированных тестов: `AFARA_STAGE=build node --import tsx --test tests/editorial.test.ts tests/consultant.test.ts`.
3. В настроенном окружении PostgreSQL/CMS запустить `npm run content:visuals` для плана. Команда `npm run content:visuals -- --apply-drafts` подготавливает черновики; опубликованные версии не заменяются. Перед массовой операцией проверить существующие черновики редактора.
4. Проверить и опубликовать медиа, затем страницы. Подтвердить доступность услуг; ответы базы знаний требуют одобрения. Не выдавать концепции за реальные работы.
5. Настоящий Telegram добавить позже в «Сайт и контакты → Подтверждённые мессенджеры». Пока адрес отсутствует, кнопки ведут к форме сообщения.
6. Для QR задать реальный публичный HTTPS-адрес в `AFARA_PUBLIC_URL` либо `APP_URL`. Префикс `/Afara/` поддерживается.
7. Для генеративного режима консультанта настроить серверный ключ провайдера и лимит. Без ключа доступен поиск опубликованных ответов. Автоматическое обучение на сообщениях посетителей не включается.

Эта передача файлов не выполняет миграции рабочей базы, публикацию CMS, слияние с `main` или обновление GitHub Pages.
