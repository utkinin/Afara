# Визуальная концепция AFARA

`afara-ai-concept.png`: сгенерировано 15.10.2026 инструментом OpenAI image generation специально для разработки AFARA. Запрос: оригинальный тёплый архитектурный интерьер, сливовый бархат, прозрачный тюль, камень и дерево, без текста и товарных знаков. Не фотография выполненного объекта и не подтверждение портфолио AFARA. Исходный эскиз пользователя использован только как направление композиции, не вставлен в страницу и не разрезан на изображения.

Использование только в development seed; production seed запрещён. Перед публичным запуском владелец заменяет материал своими фотографиями с подтверждёнными правами либо отдельно утверждает публикацию подписанной концепции. Окончательные права и применимые условия использования согласуются владельцем. Шрифты из Fontsource, SIL OFL, файлы лицензий в установленных пакетах.
