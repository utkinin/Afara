# Проверка аналитики AFARA

Изменение подготовлено поверх main `a305a8678e03ac7df0a6e37f2034d503115e7b1d`.

## Проверки в локальном окружении

- TypeScript и ESLint без предупреждений.
- Production build компилирует приложение, штатную админку и три новых API-маршрута.
- Девять Node-тестов: очистка UTM/referrer, безопасная схема событий, распознавание источников и границы прокрутки, подпись/срок cookie, production MFA; 32 черновика, офлайн-вывод без CMS/SMTP/БД и безопасный повторный импорт; согласованная JSON-LD-разметка и защита от вставки script.
- `git diff --check`.

## Интеграционный тест в CI

`tests/analytics.integration.test.ts` запускается стандартным `npm test` после подъёма настоящих PostgreSQL и приложения. Запись разрешена только при AFARA_STAGE=development и точном имени синтетической базы `afara_ci_acceptance`. Тестовые документы прямо помечены синтетическими. Действующая CMS владельца не используется.

Проверяются:

1. Нет событий и идентификатора до выбора; отказ сохраняется при перезагрузке.
2. Разрешение создаёт HttpOnly cookie; JavaScript не видит её значение; последующий переход сохраняет визит и реальную рекламную метку.
3. Путь записывается без query/hash, время предыдущего просмотра обновляется beacon, контактоподобные поля и cross-origin POST отклоняются.
4. Обычная заявка принимается без атрибуции; необязательная галочка изначально пуста и не required; отмеченная галочка связывает только собственный просмотр и сохраняет доказательство отдельного согласия.
5. Реальный отчёт PostgreSQL и native Payload view показывают путь/связанные заявки ADMIN; публичное чтение и прямой доступ EDITOR закрыты.
6. Desktop/mobile скриншоты отчёта сохраняются в `docs/screenshots/analytics-admin-1440.png` и `analytics-admin-390.png`, затем попадают в штатный CI artifact. На них только синтетические данные.
7. Локальный отказ немедленно останавливает события даже при сетевом сбое удаления. Успешный отзыв удаляет события/визиты и обнуляет связи, сохраняя контакт заявки; позднее событие без согласия отклоняется; очистка срока хранения удаляет истёкшую запись.
8. Прокрутка до конца сохраняется как 100% достигнутой высоты. Это не показатель прочтения. Отдельный интеграционный тест проверяет импорт ответов, сохранение черновика владельца, повторный запуск и закрытость служебных источников после публикации.

Фактический результат интеграционного теста и всего набора проверок определяется завершённым статусом GitHub Actions для PR этой доработки. Наличие теста не считается подтверждением его успешного выполнения.

## Производительность и границы

Нет сторонних SDK, geolocation API, session replay, перехвата форм, canvas/WebGL и новых npm-пакетов. Контроллер загружается после согласия; heartbeat — максимум раз в 20 секунд при накоплении активности, с обновлением существующей строки. Сервер ограничивает тело запроса, частоту и допустимое время. История — до 90 дней; отчёт ограничен периодом и числом строк.

Отдельный браузерный контроллер с используемыми функциями очистки URL и прокруткой после minify — 4 467 B, gzip — 2 018 B. Измерено существующим esbuild без добавления зависимостей. Это не суммарный размер React-баннера, общих Next/React чанков или всего сайта; фактическое HTTP-сжатие зависит от размещения. Библиотека ответов и JSON-LD не добавляют клиентский JavaScript.

Это не полевые Core Web Vitals и не тест физических устройств. Достоверность метрики ограничена согласием, сетью, браузером и невозможностью восстановить скрытый органический запрос.

В текущем рабочем окружении нет DATABASE_URL, APP_URL и .env.local действующей CMS. Миграция рабочей базы, публикация юридических документов и фактическое включение сбора здесь не выполнялись. GitHub Pages остаётся статическим просмотром без аналитического backend. Порядок активации — [ANALYTICS.md](ANALYTICS.md).
