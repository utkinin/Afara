# AFARA — публикация и проверка 18.10.2026

## Реализовано и применено

В рабочей CMS опубликованы **20 страниц, 74 одобренных ответа и 43 активных изображения**. Неопубликованных FAQ больше нет. Главная и «Пошив по эскизам» содержат интерактивный блок ткани; главная — выбор задачи с переносом описания в форму. Существующие направления, партнёрство/white label, изготовление по эскизам, диапазон 3–6 м, география по России и отправка в ОАЭ сохранены.

Публикация ответов: 33 прежних публичных ответа сохранены, добавлены два ответа блока ткани и 30 новых материалов библиотеки; две совпадающие темы не дублировались. Девять прежних FAQ проверены и опубликованы по прямому указанию владельца. В трёх удалены редакционные/внутренние формулировки; остальные исходные тексты сохранены. Итог девяти — `content/published-faq-2026-10-18.json`.

Изменения админки установлены: native-отчёт «Аналитика», источники/UTM и ограниченная история визита, активное время и достигнутая высота, отдельная добровольная связь с заявкой, удаление истории; закрыто от EDITOR/анонима. Поле источников/ограничений знаний доступно сотрудникам, не публичному API и консультанту. В рабочей CMS аналитика пока выключена: реальные юридические документы не предоставлены.

## Исправления и очистка

- Сравнение снимков контента вынесено в один общий модуль; порядок ключей объекта не вызывает ложного конфликта.
- Команды добавления задач и ответов завершаются после транзакций и flush stdout; зависание на удерживаемом соединении адаптера устранено.
- Добавлен явный `--publish-reviewed`: публикуются только неизменённые проверенные записи библиотеки, без подмены правок владельца. По умолчанию импорт по-прежнему создаёт черновики.
- Убрана SMTP-проверка, блокировавшая запуск CMS/страниц при недоступной почте. Уведомления остаются в постоянном outbox, TLS и тайм-ауты отправки сохранены.
- Runtime Docker собирается одним слоем приложения, без повторной копии standalone node_modules. Включены исходники CLI/worker и content, dev-зависимости не устанавливаются в runtime; пользователь node.
- Статические скрипты получают версии по содержимому, включая ленивый импорт контроллера ткани. Это предотвращает использование браузером старого скрипта после обновления HTML.

История версий, старые опубликованные архивы и CMS-медиа не удалялись как «лишние». Из Git-изменений убраны повторно сгенерированные старые тестовые скриншоты; новые снимки текущего сайта и новой админки добавлены отдельно.

### Production-образ

Образ `afara:release-20261018` собран и запущен с AFARA_STAGE=production. Digest: `sha256:53d85b3b88854a7ea587aa716ab0133504056f2444c3a3890864c84f60fc2530`.

- Главная, партнёры и пошив дали HTTP 200; присутствуют CSP и серверная JSON-LD-разметка.
- `/admin`, `/admin/analytics`, заявки, настройки уведомлений и коллекции аналитики без MFA-допуска дали 403.
- Readiness работает при намеренно недоступном SMTP; контрольный локальный ответ — 176 ms (не показатель полевых Core Web Vitals).
- Реальный POST заявки дал 201, повтор с тем же ключом — 200 без дубликата. Веб-процесс имел недоступный SMTP, отдельный worker доставил сохранённое уведомление через авторизованный STARTTLS в изолированный Mailpit. Проверка сертификата включена; тестовый CA доверялся только тестовым контейнерам. Это не подключение внешнего почтового провайдера.
- CLI миграций выполнен из того же образа. Production Compose проверен с синтетическими настройками. Тестовые документы/заявка удалены, тестовые контейнеры остановлены.

Fingerprint: `89cacde3e64d20b922fe3050f042030437223b5867bb3bc8fbef881e7af794b3`. Неполная эталонная база отвергается. Повторный штатный `db:migrate` ничего не переписывает.

Сверка содержимого подтвердила сохранение прежних 20 страниц, 33 опубликованных ответов, 40 активных медиа, настроек сайта и истории версий. Менялись только явно добавленные секции и девять одобренных FAQ. Итоговый dump восстановлен в новую `afara_transfer_acceptance`: 20 страниц / 74 ответа / 43 медиа, штатные миграции завершаются без повторного применения. ## Что ещё требует реальных материалов и настроек

Реальные фотографии и кейсы, имя/портрет специалиста, рабочие контакты, реквизиты и документы оператора. Для хостинга — домен/HTTPS, постоянные volumes, SMTP с действующим получателем уведомлений, персональный доступ/MFA и внешние backups. Юридические документы автоматически не создавались; реальные заявки и аналитика включаются после их заполнения. Для генерации ответов модели нужен отдельный секрет/включение; сейчас проверен поиск с цитатами, платный AI не вызывался.

`npm audit --omit=dev` на 18.10.2026: 0 high/critical, 5 moderate и 1 low в транзитивных инструментах esbuild/Drizzle/tsx. Advisories относятся к esbuild development server и Windows; такой сервер здесь не запускается, production-образ Linux. Автоматического поддерживаемого npm fix не предложено; несовместимые массовые обновления ради нулевого счётчика не выполнялись. Повторить проверку зависимостей перед внешним запуском.

Повторная загрузка сайтов производителей из этой среды отклонена сетью; редакционные ссылки/ограничения сохранены, новая онлайн-проверка паспортов конкретных тканей не заявляется. Семантика остаётся редакционной картой, без вымышленных частотностей и обещаний позиций.
