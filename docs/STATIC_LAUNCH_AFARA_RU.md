# AFARA.ru: бесплатная проверка спроса

Домен: **afara.ru**, регистратор — active.domains. Контакт владельца: **https://t.me/Ilya_Utkin**. Хостинг для этого этапа — Netlify Free; сервер, CMS и PostgreSQL не запускаются.

## Состав

21 опубликованная страница из снимка `bea28415a6f95502d08dca8334b14e8fce35dc3e`. Все иллюстрации, направления и FAQ сохранены. Демо-форма заменена Telegram. Выбор задачи открывает подготовленный текст в Telegram; посетитель проверяет и отправляет сообщение сам. Блок ткани передаёт параметры в локальный черновик у кнопки связи. Прямые кнопки работают и без JavaScript.

Телефон, email, юридические реквизиты и отзывы не выдумываются. Изображения не объявляются выполненными объектами. Новых внешних скриптов, cookies, аналитики, сбора данных или автоматической отправки сообщений нет. Клик в Telegram не считается заявкой. Обращения первоначально отмечаются владельцем вручную; отсутствие посещений не является проверкой спроса.

Для домена подготовлены canonical, Open Graph, sitemap, robots, базовая Organization/WebSite/WebPage-разметка и QR-код контактов. Микроразметка не содержит вымышленных цен, рейтингов или адреса. Изолированный старый URL партнёров перенаправляется на действующий. Неизвестная страница возвращает 404, а не главную с HTTP 200.

## Воспроизведение

Из checkout main с установленными npm-зависимостями:

```bash
python -m pip install -r scripts/static-launch-requirements.txt
git fetch origin bea28415a6f95502d08dca8334b14e8fce35dc3e
mkdir /tmp/afara-static-source
git archive FETCH_HEAD | tar -x -C /tmp/afara-static-source
python scripts/build-static-launch.py --input /tmp/afara-static-source --output /tmp/afara-static-dist
AFARA_STATIC_ROOT=/tmp/afara-static-dist python tests/static-launch.test.py
```

Исходный снимок читается без записи. Выходная папка должна быть новой и пустой. CMS, приватные backup, env, node_modules, старые инструкции и архивы не копируются. Версия источника фиксируется в content/static-launch.json и release.json. Обновление из CMS — отдельная осознанная смена снимка, не автоматический импорт чужой базы.

## Действия в Netlify

1. Войти в свой аккаунт на https://app.netlify.com/ и оставить тариф **Free**, без платных дополнений. Без подключённого аккаунта проект в этой сессии не создан.
2. Для ручной публикации открыть https://app.netlify.com/drop и загрузить **распакованную папку** готового пакета. В корне должны лежать index.html, assets, _headers, _redirects и netlify.toml. Загружать исходный Next.js-проект из main не нужно.
3. Либо подключить GitHub-репозиторий **utkinin/Afara**, ветку **launch/afara-ru** после её подготовки: build command пустой, publish directory `.`. В этой ветке только готовая статика; main остаётся серверным проектом.
4. Проверить выданный фактический адрес `…netlify.app`, главную, школу/детский сад, контакты и переход в Telegram. На мобильном устройстве без VPN проверить загрузку через используемых оператора и провайдера. Публичная документация не подтверждает доступность из каждой российской сети.
5. В Domain management добавить **afara.ru** и **www.afara.ru**. Основной домен — **afara.ru**. Netlify выдаст конкретные инструкции DNS/подтверждения владения. Если домен уже привязан к другому аккаунту Netlify, пройти штатную проверку владения, не создавать обход.

## DNS в active.domains

Домен не переносится к другому регистратору. Сначала сохранить текущую DNS-зону, включая MX/TXT/DKIM/SPF/DMARC, CAA и DNSSEC. Не удалять записи почты и не менять NS вслепую. При проверке 21.10.2026 Google DNS и Cloudflare DNS вернули NXDOMAIN для afara.ru; это наблюдение публичной DNS, а не проверка регистрации/прав владельца.

Если DNS-хостинг регистратора уже действует и используется стандартная сеть Netlify:

| Имя | Тип | Значение |
|---|---|---|
| @ | A | `75.2.60.5` — штатный fallback Netlify; сверить с выданной панелью инструкцией |
| www | CNAME | **Фактическое** имя проекта `…netlify.app`, без https и пути |

При поддержке ALIAS/ANAME предпочтителен `@ → apex-loadbalancer.netlify.com` вместо A-записи. Обычный CNAME на корне зоны не создавать. Если DNS-хостинга пока нет, после добавления зоны в Netlify можно назначить **именно выданные аккаунту NS** в active.domains. Имена NS не выдумывать; существующие записи предварительно перенести, DNSSEC согласовать.

После DNS проверить afara.ru/www, выпуск и автопродление HTTPS, редирект www→afara.ru, canonical, sitemap и QR. DNS/IP не заменяют добавление домена в Netlify. Запись CNAME для www пока невозможно завершить без фактического имени проекта. Вход/пароль регистратора и токены не передаются через публичный GitHub или чат.

Официальная схема DNS: https://docs.netlify.com/manage/domains/configure-domains/configure-external-dns/ . Free имеет лимит 300 кредитов в месяц; по исчерпании сайт приостанавливается, поэтому это тест, а не обещание безлимитного размещения. Следить за Usage; перед оплаченной рекламой проверить запас лимита и реальную доступность.
