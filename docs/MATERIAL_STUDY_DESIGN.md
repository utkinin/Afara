# Свет, фактура и предварительная сборка

Решение от 17.10.2026 для существующего AFARA. Фреймворк «Язык дизайна / Вкус / Движение» использован как направление работы с интерфейсом. Сторонние skills, плагины и библиотеки анимации не устанавливались.

## Что внедрено

- На главной и странице «Пошив по эскизам» подготовлен блок `material-study`: нейтральное освещение, тёплое освещение, фактура, увеличение изображения, схема предварительной сборки и выбор одного либо двух слоёв.
- Три исходные иллюстрации созданы для AFARA. Световые версии — самостоятельные кадры одной композиции, без CSS-фильтра с обещанием точной цветопередачи. Макроизображение иллюстрирует поверхность, а не документирует конкретный артикул или масштаб 1:1. Происхождение и промпты записаны в manifest; служебное поле CMS `source` не публикуется посетителям.
- Выбор переносится в штатную форму только после нажатия кнопки. Уже введённое описание сохраняется. Сам просмотр не отправляет заявку и не сохраняет контактные данные.
- Сохранена палитра AFARA: ivory, сливовый акцент, графит; локальные Cormorant Garamond и Manrope. Заголовок нового блока 36–60 px, основной текст 18–20 px, элементы управления от 44–56 px. На мобильном — одна колонка, обычный скролл и отдельный полноразмерный просмотр с Escape и возвратом фокуса.

## Что исправлено в исходной идее

| Предложение | Принятое решение |
|---|---|
| Next.js 14, Tailwind и Framer Motion | Используется текущий совместимый стек Next.js 16 / React 19 / Payload 3. Новых зависимостей нет. |
| «Дневной 4000 K / вечерний 3000 K» | Нейтральный и тёплый свет без измеренных значений. Цветовая температура не обеспечивает точной цветопередачи экрана. Для заказа нужен реальный образец при освещении объекта. |
| Ниша 15–16 см для сборки 1,7 | Такая формула не используется. Нужны выбранные профили, число рядов, ход складки, выступы окна и возможность обслуживания. |
| Blackout 100%, Dimout 80% | Универсальные проценты не публикуются. Нужны данные конкретной ткани, системы и условий проверки. |
| Калькулятор расхода и цены | Только предварительный визуальный выбор. Схема не определяет расход, конструкцию, стоимость или размеры ниши. Коэффициент 1,7 не объявляется универсально оптимальным. |
| Раздвижка всего сайта, параллакс, тяжёлый blur | Начальный контент сразу доступен. Переход выбранного кадра: opacity/transform, 320 мс, cubic-bezier(0.25,1,0.5,1), без анимации layout. Ограниченный blur 8 px только под маленькой кнопкой на desktop. |
| Утяжеление всех переходов spring-анимацией | Нативные CSS/Web Animations; reduced motion отключает движение. Никакой задержки навигации ради эффекта. |

## Скорость и структура кода

Основной блок отдаётся сервером. Маленький React-компонент подключает независимый контроллер около области просмотра через IntersectionObserver. Тот же контроллер используется статическим превью: две разные реализации поведения не поддерживаются.

Первый кадр — responsive WebP с фиксированным контейнером и lazy loading ниже первого экрана. Остальные варианты находятся в инертных HTML template и загружаются только при выборе. Используются размеры 480/960/1536 px. Для hero с отдельным мобильным кадром настроены `sizes` и responsive srcset; у desktop сохранён свой набор размеров. Без мобильного кадра сохранён прежний запас разрешения для вертикального cover из горизонтального фото. В проекте остаётся один конвейер оптимизации, без повторной обработки Next Image поверх готовых производных CMS.

Не добавлены карусель, видео, внешний шрифт, трекер, canvas/WebGL, новый API, состояние в localStorage или серверные запросы конфигуратора. Для изображений предусмотрен отказ: предыдущий загруженный кадр остаётся, появляется понятное сообщение. Статический генератор обрабатывает также ресурсы внутри template.

## Первичные источники для проверки решений

- [Silent Gliss: Understanding Recessed Curtain Tracks](https://www.silentgliss.co.uk/engb/expertise/understanding-recessed-curtain-tracks/) — выбор системы и планирование ниши зависят от конструкции. Числа отдельной системы не перенесены в универсальный совет AFARA.
- [Création Baumann: Verdunkelungsstoffe](https://creationbaumann.com/textilien/verdunkelungsstoffe/) — свойства затемняющих тканей рассматриваются для конкретных материалов; общий процент для всех dimout не задан.
- [X-Rite: Lighting and Visual Evaluation](https://www.xrite.com/learning-color-education/videos/lighting-and-visual-evaluation-the-color-lab) — освещение и условия визуальной оценки влияют на цвет. Иллюстрации не заменяют оценку образца.

## Граница поставки

Наличие скрипта или нового публичного превью само по себе не подтверждает применение данных в CMS. Порядок — [APPLY_MATERIAL_STUDY.md](APPLY_MATERIAL_STUDY.md).
